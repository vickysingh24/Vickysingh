## Publish on GitHub Pages
1. Create a repository, for example `vicky-portfolio`.
2. Upload all files and the complete `demos` folder. Do not upload only the ZIP.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. After deployment, your main portfolio will be at `https://YOUR-USERNAME.github.io/vicky-portfolio/`.
6. Demo links will work under `/vicky-portfolio/demos/salon.html`, `/cafe.html`, `/coaching.html`, `/boutique.html`, and `/consultant.html`.
